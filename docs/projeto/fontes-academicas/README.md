# Fontes acadêmicas preservadas

As cópias são idênticas aos arquivos fornecidos pelo usuário. Nomes originais,
tamanhos, SHA-256 e localização no LaTeX constam de `PROVENIENCIA.json`.
O recebimento em 03/11/2026 não é a data de realização das atividades.
Os campos de data dos dois documentos estão em branco.

- Prática 1: Word, quatro páginas após renderização (a última em paisagem).
  Contém roteiro e respostas dos itens 1–5, estimativas e quadro adicional 5.1.
- Prática 2: PDF, oito páginas em paisagem. Página 1: objetivos e fundamentação;
  páginas 2–3: etapa 1; página 4: etapa 2 e roteiro da etapa 3; página 5:
  backlog e início da etapa 4; páginas 6–7: continuação do plano de M-01;
  página 7: sprints; página 8: reflexão e orientação de apresentação.

O usuário determinou o uso do plano coletivo para a etapa 4 da Prática 2.
Não há atribuição de autoria individual nem comprovação de execução das ações.
As instruções acadêmicas dos roteiros são descritas no capítulo; não são
comandos operacionais para o repositório.

As versões originais incluem cabeçalhos e diagramação próprios. O capítulo
consolida o conteúdo em LaTeX, sem reproduzir problemas visuais dos originais.
